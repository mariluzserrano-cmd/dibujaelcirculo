# Ronda 12 · Siempre el protagonista es Jesús

Este paquete es una copia independiente de la experiencia de la Ronda 12 de **Dibuja el Círculo**.

## Qué conserva

- Los 40 días con búsqueda, filtros, progreso y notas personales.
- Los seis encuentros y sus materiales.
- Las memorias comunitarias: imágenes y video.
- Cuatro recursos visuales descargables.
- El logotipo original e inclusivo de Circuleños y Circuleñas.
- Diseño adaptable para computadora, tableta y celular.

Los botones de cada día y de cada encuentro abren los materiales que ya están publicados en el repositorio `mariluzserrano-cmd/dibujaelcirculo`. Las imágenes, el video de memorias, el diseño y la programación de esta bitácora sí viajan dentro de este paquete.

## Cómo probarla antes de subirla

1. Descomprime el archivo ZIP.
2. Abre `index.html` en Chrome, Edge o Safari.
3. Comprueba varias tarjetas de los 40 días.
4. Abre los encuentros y la sección **Memorias**.
5. Prueba el botón **Descargar mi diario**.
6. Cambia el ancho de la ventana o ábrela desde el celular para revisar la versión móvil.

## Cómo subirla a GitHub Pages

1. Crea una carpeta para esta ronda dentro del repositorio; por ejemplo: `ronda12-siempre-jesus`.
2. Sube **todo el contenido** de esta carpeta, manteniendo juntos:
   - `index.html`
   - `app.js`
   - `styles.css`
   - la carpeta `assets`
3. Confirma los cambios en la rama que publica GitHub Pages.
4. Abre la dirección resultante, que tendrá una forma parecida a:
   `https://mariluzserrano-cmd.github.io/dibujaelcirculo/ronda12-siempre-jesus/`
5. Haz una última prueba desde computadora y celular.

## Importante

No borres ni muevas la carpeta `assets`: contiene el logotipo, las memorias y los regalitos descargables. El progreso y las reflexiones se guardan localmente en el navegador de cada participante; no se publican ni se comparten.

La ronda debe eliminarse del website principal **solamente después** de comprobar que esta copia abre correctamente desde GitHub Pages.
